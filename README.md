# Gun Duel (TaCZ guns server)

1. Get the **Modrinth App** (modrinth.com/app) if you don't have it. Prism Launcher works too.
2. Download **[GunDuel-1.1.0.mrpack](https://github.com/idkhowtonamemyselfasadev/gun-duel/releases/latest/download/GunDuel-1.1.0.mrpack)** → Modrinth App → *+ (Create instance)* → *Import* → pick the file.
   That's Minecraft **1.21.1** with Fabric, TaCZ guns and Keybind Fix Plus. Keep all the mods, the guns don't
   shoot without Keybind Fix Plus.
   **Mac / 8 GB laptops:** instance → Settings → Java → Memory → **3072 MB** (the pack already has Sodium and
   light video settings; raise render distance if you have fps to spare).
3. Launch it → Multiplayer → **Gun Duel** is already in the list (85.214.218.112:25580).
   Tim has to whitelist your name first.

**Playing:** right-click the compass → pick 1v1 / 2v2 / 3v3 / 4v4. When the queue is full the match starts.
Each round you pick 1 of 2 random guns (+ a Glock), ammo is infinite, no respawns, first to 7 rounds.

**Controls (TaCZ):** left click shoot · right click aim · R reload · G fire mode (auto/semi/burst) ·
C crawl · V melee · H inspect. Change them under Options → Controls → "TaCZ".
